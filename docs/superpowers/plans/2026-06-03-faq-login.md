# FAQ Login Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a mobile-friendly FAQ entry on the login screen that links to a dedicated FAQ page.

**Architecture:** Keep the login screen as the entry point, add a lightweight public FAQ route, and style both pages with the existing app CSS so the experience stays consistent on mobile. The FAQ content will be static and self-contained; no new data layer is needed.

**Tech Stack:** CodeIgniter 4 views and routes, existing `public/assets/chilibooks.css`, standard HTML/CSS.

---

### Task 1: Add public FAQ route and controller action

**Files:**
- Modify: `app/Config/Routes.php`
- Modify: `app/Controllers/AuthController.php`

- [ ] **Step 1: Add the new GET route**

```php
$routes->get('faq', 'AuthController::faq');
```

- [ ] **Step 2: Add the controller method**

```php
public function faq()
{
    if (session('user_id')) {
        return redirect()->to('/dashboard');
    }

    return view('auth/faq');
}
```

- [ ] **Step 3: Verify the route is available**

Run: `php spark routes | rg 'faq'`
Expected: one `GET faq` route pointing to `AuthController::faq`.
